# Human Behavior

> AI-powered product analytics platform. Autonomous agents watch session
> replays, auto-instrument event tracking, map product workflows, and surface
> friction, bugs, and rage clicks. Developers integrate via a first-party
> JavaScript session-recording SDK (humanbehavior-js) initialized with a
> project API key. Backed by Y Combinator, Vercel, and General Catalyst.
